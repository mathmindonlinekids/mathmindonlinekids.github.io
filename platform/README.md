# MathMind Platform

Новая платформа с личными кабинетами: методист (админ), учитель, родитель, ребёнок.
Текущий сайт для учеников (`me.html`, `practice.html`, `hw/`) продолжает работать, пока мы не переключим детей.

## Что уже есть

| Файл | Что это |
|---|---|
| `supabase/schema.sql` | База данных: роли, ученики, приглашения, навыки, программа ребёнка, задания, ключи ответов, ответы, уроки, фидбек, карта навыков и правила доступа |
| `supabase/skills.sql` | Каталог навыков: стандарты NC (3 класс), Флориды B.E.S.T. (4 класс), навыки MathMind и олимпиадные приёмы |
| `supabase/test/` | Локальная проверка правил доступа (40 проверок на вымышленных людях) |
| `app/index.html` | Вход по ссылке на email (без пароля) |
| `app/admin.html` | Кабинет методиста: все ученики, карты навыков, «В следующий урок», цвет вручную |
| `app/kid.html` | Кабинет ребёнка (на английском): уровень, кнопка «Join my lesson», карта-мир навыков |

Пока в `app/config.js` пусто, страницы работают в **демо-режиме** на вымышленных учениках.

## Цвета карты навыков

- 🟢 **закреплено**: минимум 4 ответа, 80%+ верно, в 2+ разных дня (по последним 10 ответам);
- 🟡 **в процессе**: начали, но ещё не закрепили;
- 🔴 **не освоено**: меньше 50% верно (минимум 2 ответа);
- ⚪ **ещё не проходили**.

Методист или учитель может поставить цвет вручную, ручной цвет важнее автоматического.
Ребёнок красного не видит: у него это «Coming soon» 🔒.

## Кто что видит (это проверяет сама база)

| | Методист | Учитель | Родитель | Ребёнок |
|---|---|---|---|---|
| Ученики | все | только свои | только свои дети | только себя |
| Карта навыков с цветами | ✅ | ✅ | ✅ | ⭐/🚀/🔒 вместо цветов |
| Каждый ответ, ошибки | ✅ | ✅ | — | — |
| Ключи ответов | ✅ | ✅ | — | — |
| Заметки учителя, черновик фидбека | ✅ | ✅ | — | — |
| Отправленный фидбек | ✅ | ✅ | ✅ | — |

Роль нельзя выбрать самому: её даёт приглашение от методиста.

## Подключение Supabase (один раз)

1. Зарегистрироваться на supabase.com и создать проект (регион: US East).
2. SQL Editor → выполнить `supabase/schema.sql`, затем `supabase/skills.sql`.
3. Authentication → URL Configuration: добавить адрес сайта (например `https://mathmind.kids`).
4. Project Settings → API: скопировать Project URL и anon key в `app/config.js`.
5. Перед тем как завести настоящих детей: перейти на тариф Pro (ежедневные резервные копии).

**Данные настоящих детей никогда не кладём в этот репозиторий** (он публичный). Они хранятся только в Supabase.

## Локальная проверка базы

```bash
createdb mm
psql -d mm -f supabase/test/supabase_stub.sql -f supabase/schema.sql -f supabase/skills.sql -f supabase/test/rls_test.sql
```

Последняя строка должна быть `ALL ACCESS CHECKS PASSED`.
